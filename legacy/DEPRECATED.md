# УСТАРЕЛО — заменено Terra Realis 2.0

`mushoku-magic-1.0.0.jar` и текстуры в этой папке — **старый мод репозитория. Он больше не
сопровождается и не должен использоваться.** Его роль взял на себя мод генерации мира
**Terra Realis** (корень репозитория):

- при создании мира тип **Default** использует генератор Terra Realis
  (`data/minecraft/worldgen/world_preset/normal.json`);
- магическая интеграция старого мода заменена публичным API нового:
  `dev.terrarealis.fabric.LeyLines` (`manaAffinity(x, y, z)`, `isLeyNode(x, z)`);
- ни один блок, предмет или биом старого мода в новой генерации не используется.

Файлы сохранены только для истории репозитория. Не кладите старый jar в `mods/` вместе с новым:
он не рассчитан на Minecraft 1.21.11 и не даёт ничего, чего не даёт Terra Realis.
